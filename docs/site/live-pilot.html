Bounded live evidence · 2026-07-28

Both designs passed. The simpler one was recommended.

On one synthetic operator-doc-gap scenario, direct and loop each completed three accepted runs using gpt-5.6-terra at medium reasoning effort. Because both cleared the declared gates, lower complexity decided the result.

Hard evidence boundary: one synthetic scenario, one model/configuration, and three repetitions per candidate. Deterministic checks are not independent semantic grading. This is not a benchmark, generalization, production outcome, or ROI claim. The price-card value is an estimate—not a provider invoice.

Why this is useful

Technical signal

The live path is measurable

The run retained acceptance, calls, token usage, retries, elapsed time, configuration, and price-card estimates for each candidate. The selection rule stayed the same: hard gates first, then least complexity.

Business signal

Complexity needs evidence

A more elaborate workflow was not rewarded merely for being elaborate. When observed quality tied, the system recommended the option with the smaller operational burden.
