Architecture

Scenario, SLO, trusted Policy, and Blueprint pass through closed-shape and semantic validation. The compiler binds each accepted route outcome to implemented behavior. The runner reserves resources, invokes one role at a time or a bounded parallel wave, validates the returned contract, and records the exact node and edge. A broker mediates capabilities and the data-only effect simulation.

The Blueprint node kinds are model, deterministic, fork, join, approval, effect, and terminal. Every node, edge, and cycle is finite.

Selection

  1. Reject structurally invalid candidates.
  2. Reject missing mandatory/conformance requirements.
  3. Reject contract or bounded-termination failures.
  4. Reject authority or approval failures.
  5. Reject call, token, latency, or spend-budget failures.
  6. Pareto prune feasible candidates.
  7. Select the least structurally complex evaluated candidate.
  8. Run within-family ablations only after canonical selection.

Portable evidence inputs

Scenario Packs carry source provenance and an explicit claim boundary. Price Cards carry currency, effective date, exact model rates, service/context assumptions, exclusions, and public rate provenance. The runtime validates and snapshots both.

node agent-wind-tunnel.mjs validate \
  --scenario-pack scenarios/enterprise-portfolio/calibration.json

node agent-wind-tunnel.mjs validate \
  --price-card price-cards/openai-standard-short-context-2026-07-28.json

Safe live preview

node agent-wind-tunnel.mjs run \
  --adapter openai \
  --dry-run \
  --scenario operator-doc-gap \
  --candidates direct,loop \
  --repetitions 3 \
  --price-card price-cards/openai-standard-short-context-2026-07-28.json

The preview makes zero API calls. Confirmed work separately requires --confirm-live, --max-live-spend-usd, a call envelope below --max-live-calls, and an authorized key. Cost values are estimates, not invoices.

Authority

A node request is allowed only when that exact capability and scope were compiled for the requester and already exist in the immutable initial grants. A consequential simulated effect additionally needs a unique dominating approval node and an approval bound to the run, scenario, Blueprint, artifact hash, capability, scope, and effect. The graph cannot grant itself permission.

Evidence package

The report includes canonical JSON, a metadata-only role-call trace, a separate exact execution ledger, Markdown/HTML reader surfaces, and a manifest of file membership, bytes, and SHA-256 hashes. Fixture runs are byte-reproducible. Live runs retain IDs, usage, configuration, and nondeterministic status.
